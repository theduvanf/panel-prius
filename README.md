# Panel Prius

Pantalla tipo CarPlay para mi Toyota Prius C 2014 en una tablet Android.

- Velocidad, RPM, acelerador, temperatura y batería híbrida en vivo con un adaptador OBD-II Bluetooth LE.
- Carro en 3D, mapa y modo EV / gasolina.
- Abre las apps instaladas en la tablet (Spotify, Waze, Lyft Driver…).
- Se puede usar como pantalla de inicio de la tablet.

**Descargar:** https://github.com/theduvanf/panel-prius/releases/latest/download/PanelPrius.apk

Cada cambio que se sube a `main` construye una APK nueva automáticamente.
